# Tabaristan — The Hyrcanian Realm

A vast, atmospheric open 3D world of ancient Tabaristan (northern Iran): a winding river
falling through a forested gorge, dense Hyrcanian forest on the mountain slopes, drifting
mist and birds, and an ancient citadel on the eastern shoulder — all generated by code
with **WebGPU** and **WGSL**. No images, no models, no sound files, no libraries.
Everything ships in **one 153 KB `index.html`** ready for GitHub Pages.

## Run it

Deploy `index.html` to any static host (GitHub Pages: push the file, enable Pages),
then open it in a **WebGPU browser** (Chrome / Edge 113+, or any current WebGPU-capable
browser). WebGPU must be enabled — it is by default in current Chrome and Edge.

- **Mouse**: click to capture the pointer, drag to look
- **W A S D** move · **Q / E** down / up · **Shift** haste
- **1 – 6** jump to viewpoints (meadow, waterfall, forest trail, fortress gate, ridge vista, river bend)
- **M** mute · **H** stats (fps, worst frame, GPU ms, render scale) · **Esc** menu
- **Touch**: one finger looks, two fingers move; phones are offered landscape fullscreen

## What is in the world

| System | Implementation |
| --- | --- |
| Terrain | A single analytic height function (fractal + ridged noise with domain warp) evaluated twice: CPU builds a 307 k-triangle near mesh in 16 frustum-culled chunks; the same function in WGSL displaces an 11.8 k-triangle far-mesh ring out to ±2.5 km. The two agree because every arithmetic step of the CPU noise goes through `Math.fround` — bit-for-bit identical to the f32 GPU math. |
| Fortress | A procedurally assembled citadel: 10-sided curtain wall with merlons and arrow slits, eight battered towers with machicolations and domed kiosks, a gatehouse with pointed arch, timber doors and a turquoise tile band, a keep with arched windows, corner turrets and a glazed dome. A raised causeway ramp (part of the height function) carries you from the valley to the gate. |
| Forest | ~10 000 trees in three species (beech-like broadleaf, ironwood with amber crowns, cypress) — instanced trunk tubes plus alpha-tested canopy cards fed by a baked foliage texture. Dense on north slopes and near water, sparse at the treeline, with clearings and a treeline that follows the altitude. |
| Undergrowth | ~34 000 instanced grass blades / fern rosettes / poppies / sedge tufts as 8-vertex strips, with per-type shaping and colour, wind sway and translucency. |
| Water | An analytic river surface with 8-direction wave normals, depth read back from the height function in the shader (so banks, shallows and the plunge pool match the bed exactly), depth-based absorption, caustic sparkle, animated foam at the banks, fresnel sky-and-cloud reflections and sun glints. A 23 m waterfall sheet with eroded streaks and spray feeds a mist-particle plunge pool — with a walk-in grotto beside the falls. |
| Sky & light | Procedural golden-hour dome with sun disc, mie glow and a two-plane cloud layer (baked tileable fbm + cirrus), height + distance haze with warm inscatter, volumetric light shafts (half-res shadow-map march with depth-aware blur and upsample), soft PCF shadows from a shimmer-snapped orthographic cascade, bloom, ACES-style tonemap, vignette and dithering. |
| Life | Circling bird flocks and lone eagles with flapping wings, drifting pollen motes, falling leaves, waterfall mist, waving banners on the fortress towers. |
| Audio | Fully synthesized: gusting wind, leaves rustling by forest density, river and waterfall roar by distance, songbird phrases, a crow, a distant eagle — Web Audio graph with a convolution reverb built from generated noise. |

## Performance

- **GPU instancing everywhere** — one draw call per cell run per mesh; a typical frame issues ~190 draw calls for the whole scene.
- **Cell culling** — all vegetation, rocks and instance sets are packed into a 24×24 grid with per-cell Y ranges and merged frustum-culled runs (nearest rows first), like the terrain.
- **No CPU mesh work per frame** — wind, water, birds, flags and particles are animated entirely in vertex shaders.
- **Three quality tiers** (High / Medium / Low on the menu) choose MSAA 4×/1×, shadow-map size 4096/2048, foliage thinning (every 1st/2nd/4th instance), ray-march step count and texture sizes. The tier auto-selects from `navigator.deviceMemory` and pointer type, remembers your choice, and **downgrades automatically if the graphics device is lost**.
- **Adaptive resolution** — every second the frame time (or GPU timestamps, when available) scales the internal render resolution between 0.23 MP and 2.56 MP, then the draw-distance factor; both persist across visits.
- Mobile stays playable: reduced foliage density, no MSAA, fewer ray steps, lower base resolution, and a coarse-tier particle budget.

## Source layout

The readable sources live in `src/` (concatenated by `src/build.js` into the single
`index.html` — run `node src/build.js` to rebuild after editing):

`quality.js` (tier selection) → `math.js` (f32-exact noise twin, RNG, mesh builder,
terrain mesher) → `world.js` + `world2.js` (density fields, fortress, grotto, placement,
water, particles) → `shaders.js` + `shaders2.js` (25 WGSL modules) → `main.js`
(device, pipelines, bakes, shadow pass, culling, frame loop, input, audio, menu).

Inspired by Noniv's *abyssal-garden* (a single-file WebGPU underwater scene). This world
is an original implementation of the same level of ambition for a land environment —
different theme, different terrain system (analytic heightfield rather than SDF voxels),
different lighting palette, original code throughout.
